# Rust no esp32

## Tutorial iniciando:
1. Instalar esp-generate ```cargo install esp-generate```
2. Criar um projeto ```esp-generate```
3. (Opcional) Instalar a extensão Wokwi para simular o código no vscode https://docs.wokwi.com/vscode/getting-started
